# ResaleIQ Project Rules

- **Design Aesthetic / Color Theme**: Do NOT use the "Lux Forest" (Obsidian/Charcoal/Kinetic Green) aesthetic for this project. Maintain the current "Boutique Creame / Espresso Brown" theme (boutique-creame, espresso-brown, emerald-500, resale-gold, frosted-tan).
- **V3 Architecture Roadmap**: The ultimate moat builder for this app is "Visual Ingestion" (Claude 3.5 Sonnet for multimodal image parsing), "Data Integrity Node", "Market Truth Protocol" (pulling *real sold comps* from APIs), and "Analytical Output". When implementing features related to this, adhere strictly to the non-Lux Forest aesthetic.
